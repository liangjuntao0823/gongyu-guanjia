使用说明
  • 单人用只需 3 步：① 填好 云函数地址 / 桶 / 地域 / 自定义域名 / 密钥；② 点「保存并验证连接」；③ 正常用 App。
  • 房源文字、照片视频会自动传到云端桶；分享卡片发好友能直接看；备份会上传到云端留档。
  • 网页后台（云函数地址）可看访问统计、管理桶文件、查储存用量。
  • 换机 / 重装：填同样配置 + 恢复配置备份，下拉同步就把云端房源拉回本地。
  • 本地数据始终保留，云端只是「第二份」，断开配置也不影响本地使用。
  • 前提：几台手机填同一个桶和云函数地址，各自填不同用户名。
  • 共享的只有「房源」：一台录入上传，另一台下拉同步就能看到；删房也会同步删云端。
  • 不共享：名片、二维码、水印、分享记录、访问统计、云端备份——都按用户名分开，绝不会看到别人（备份各管各的）。
  • 用户名的作用：操作日志 / 分享 / 统计带上用户名，网页后台能看到是谁在操作。
  • 给别人用不用懂桶和云函数：配好你的后，把「配置」发给对方导入 + 填用户名即可；对方也可以自己整套部署（用下方部署包）用自己的桶。
三端互通说明（App ↔ 云函数 ↔ 网页后台）
多用户（共享房源）
多台手机填同一个桶配置、各自填用户名，即可共享房源：一台录入，另一台下拉同步就能看到。操作日志/分享/统计会带上您的用户名，其他私有数据（名片/水印/统计/备份）按用户名分开。
「保存并验证连接」会用当前配置上传测试文件并回读，成功才提示「配置正确」；「访问储存桶」用当前填写的桶名和地域打开腾讯云控制台。

点「备份配置到文件」后，备份文件（桶名_地域_日期.json，含密钥）会直接生成到 iOS「文件」App → 我的 iPhone → 公寓管家 → 「备份」文件夹，随整个「备份」文件夹一起备份即可。换机 / 重装 / 误改后，点「从备份文件恢复配置」在列表中选择备份文件（或从其他位置导入）即可一键还原。含密钥内容请勿外泄。

密钥与名片只存在本机钥匙串，不会上传到任何地方。
