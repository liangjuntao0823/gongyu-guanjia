## 5 项改动逐条说明

### ① 房源折叠头部：改按钮式手动收起/展开（不再自动）
- 彻底移除「滚动自动折叠」机制：删掉 `onListScroll` 函数及 List 上的滚动监听挂载，以后无论怎么滚都不会自动收起/展开。
- 改为按钮式：
  - **收起**：统计栏最左侧新增「收起」按钮（chevron.up 胶囊），点一下即收起统计/搜索/筛选区；
  - **展开**：收起后顶部显示一条「筛选区已收起，点此展开」提示条（chevron.down），点提示条即可展开。
- 展开状态 = 统计栏 + 搜索栏 + 筛选栏完整显示，与之前一致。

### ② 纠正上版误删：「房源统计」4 个字才删，其余全部保留
- 上一版（v2.2）误删了整条统计栏。本版先从 git 历史取回 b106 原版统计栏代码完整恢复：
  - 排序胶囊（默认/价格升/更新时间）✔
  - 数量胶囊三分支（按筛选自动切换：仅座号/户型筛选→对应统计；仅状态筛选→「状态 label X套 + 1座 X套 + 2座 X套」；无筛选→「1座 X套 2座 X套 待租 X套」）✔
- 只删除「房源统计」4 字标识（该位置被新的折叠按钮取代）。
- ⚠️ 注意：你现在手机上装的是旧包（你发的截图里统计栏还在显示，但 v2.2 代码里其实已删）——**请先安装 b110 新包再验收**。

### ③ 电表趋势图：X/Y 轴加刻度
- **Y 轴（剩余电量）**：每 5 度一刻（0 / 5 / 10 / 15 / …），上限自动向上取整到 5 的倍数；刻度字号保持原来的 9pt，不大。
- **X 轴（时间）**：每 1 小时一刻，从数据起点向上取整到整点开始（如 12:15 开始的数据，刻度从 13:00 起）；跨度超过 24 小时自动带日期（MM-dd HH:mm）；数据起点/终点不在整点时会补上首末点标签；每个数据点的横坐标改按实际时间线性映射（刷新间隔不均匀时，时间刻度与数据点也能对得上）。
- 字号保持原有大小（Y 9pt / X 8pt）。

### ④ 刷新记录行：位置对调
- 调整前：左「第 x 次刷新」、中「剩余电量」、右「刷新时间」
- 调整后：**左「刷新时间」、中「剩余电量」、右「第 x 次刷新」**（剩余电量仍在中间不变）

### ⑤ 58 / 安居客刷不出来修复 + 安居客顶栏统计
- **58 刷不出来根因**：旧代码补抓经纪人时在主页面上用信号量同步阻塞，40 条详情页如果全部超时（每条 6 秒），主线程被卡约 78 秒，整个板块表现为「刷不出来/卡死」。
- **58 修复**：
  - 读取完成**先立即展示房源列表**（标题/价格/位置立即可用），不再等经纪人；
  - 经纪人补抓改为**后台分批执行**（每批 3 个并发、单请求 4 秒超时、async 挂起不占主线程），带「正在补抓经纪人 x/40」进度条，抓失败自动降级显示「—」，不阻塞列表。
- **安居客刷不出来**：读取脚本大幅增强——
  - 验证码/反爬文案检测扩充（安全验证/人机验证/滑动验证/verify 等）；
  - 已知卡片容器都找不到时，自动降级为「全文扫描含 元/月 的链接」兜底收集（页面改版也能解析），按 href 去重、上限 60 条；
  - 解析到 0 条时明确提示原因（页面结构变化/需登录/被验证拦截），不再静默显示空数据。
  - ⚠️ 云端 IP 访问安居客前台被反爬网关拦截是已验证死路，App 内实际读取走你的手机网络，**需在手机上实测确认**。
- **安居客顶栏统计（新增）**：概览区新增三列——房源(套) / 均价(元/月) / 最高(元/月)，与 58 概览卡同风格；有数据即显示（均价、最高按抓到的房源价格现算）。
